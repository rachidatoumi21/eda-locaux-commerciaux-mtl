# EDA — Locaux commerciaux (Montréal, 2025)

## Objectif
Analyser les locaux commerciaux de Montréal et le statut **VACANT_A_LOUER** :
répartition globale, arrondissements les plus touchés (en nombre et en taux),
et distribution des vacants par secteur et type de commerce.

## Données
- Source : Ville de Montréal — Locaux commerciaux et statuts d’occupation (2025)
- Taille : 28 621 lignes, 34 colonnes

## Résultats clés
- 712 locaux “vacant à louer” sur 28 621 (≈ 2,49%)
- Top arrondissements (nombre de vacants) : Ville-Marie, Plateau-Mont-Royal, …
- Top arrondissements (taux de vacance) : centre ville, grande sud-ouest
sud-est
## Fichiers
- `EDA.ipynb` : notebook (nettoyage + analyses + graphiques)
- `data/occupation-commerciale-2025-fixed.csv` : version corrigée du CSV

## Limites
Les données représentent une photo à une date; certaines colonnes sont manquantes selon les locaux.
